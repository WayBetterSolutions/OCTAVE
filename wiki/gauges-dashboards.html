Gauges & Dashboards

Overview

OCTAVE ships with a small library of gauge primitives under frontend/gauges/ and three pre-built dashboards under frontend/dashboards/. Dashboards render inline inside the OBD menu via a Loader — the default view is the parameter-card grid, and selecting a dashboard swaps the grid for the chosen layout in place. Selection is persisted as the activeDashboard setting.

Entry point: a "Dashboards" pill at the top-right of the OBD menu opens a modal chooser listing "Parameter Cards" plus each registered dashboard. Tapping a choice swaps the content and closes the popup.

Gauges bind to the OBDParameterModel singleton by paramId (e.g. "RPM", "SPEED") — title, unit, min and max are auto-populated from the model, and the live value updates reactively as the backend polls each PID. No manual signal wiring is required.

Gauge primitives

PrimitiveUse for
CircularGaugeArc-sweep dial with optional tick marks, needle, redline and center readout. Flagship gauge for RPM, speed, coolant, etc.
BarGaugeHorizontal or vertical filled bar. Good for fuel, throttle, intake temps. Supports a warnAbove threshold that recolors the fill.
LinearGaugeHorizontal scale with tick marks and a sliding indicator. Best for bidirectional ranges that straddle zero (fuel trim, timing advance, EGR error).
DigitalReadoutBig numeric value with subdued label and unit. Use as the dominant element on a dashboard when an arc is overkill.
ArcGaugeHalf-dial (180° top arc with readout below the chord). Compact, wide-aspect alternative to CircularGauge for speedometer-style layouts. Shares the same arc/tick/needle/redline engine.
SparklineGaugeRolling history line showing recent values. Use when motion matters more than absolute value — boost, load, fuel trim. Timer-sampled so the x-axis scale stays stable; autoScale rescales the y-axis to the visible window for small-swing PIDs.
WarningLightBinary tell-tale indicator bound to a triggerAbove / triggerBelow threshold. Composable — drop several into a row for an idiot-light strip, or overlay one atop a larger gauge as a critical alert.

Built-in dashboards

DashboardLayout
SportHuge digital speed readout + large RPM dial with redline, vitals strip (coolant / oil / fuel / throttle) along the bottom.
MinimalThree round circular gauges across the screen: Speed, RPM (with redline), Fuel.
Full Grid4×2 grid of compact circular gauges covering Speed, RPM, Coolant, Oil, Throttle, Engine Load, Fuel, and System Voltage.

Authoring new gauges & dashboards

The complete API reference, all 93 supported PID IDs, theme tokens, needle-angle math, and step-by-step recipes for adding a new dashboard or a new primitive live in docs/GAUGE_AUTHORING.md. That document is the source of truth — update it whenever the gauge API changes.

Quick recipe: create frontend/dashboards/MyDashboard.qml that composes gauge primitives in a layout, then append { id, label, source } to the dashboardRegistry array in OBDMenu.qml. The chooser popup picks it up automatically.
